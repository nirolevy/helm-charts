Helm charts

This is a Helm repository. Add it with:

helm repo add nirolevy https://nirolevy.github.io/helm-charts
helm repo update
helm search repo nirolevy

The same charts are on GitHub Container Registry:

helm install qui oci://ghcr.io/nirolevy/charts/qui

Charts, documentation and source: github.com/nirolevy/helm-charts. The repository index is index.yaml.

The release workflow updates this branch. Do not edit index.yaml by hand.
